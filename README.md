# data-automation

법정동 코드와 PNU(필지 고유번호)가 포함된 격자 데이터를 정리하는 Python 도구입니다. Tkinter GUI에서 CSV 정리, 법정동 코드 누락 비교, 22×22 격자 중앙 정렬, 코드 자르기, Swift 코드 생성을 수행합니다. QGIS에서 격자별 PNU를 재배치하는 스크립트도 포함합니다.

## 설치 및 실행

Python 3, `pandas`, Tkinter가 필요합니다. QGIS 스크립트를 사용할 때는 별도로 QGIS의 Python 실행 환경이 필요하며, GUI 앱만 사용할 때는 QGIS가 필요하지 않습니다.

프로젝트 루트에서 실행합니다.

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install pandas
python main.py
```

Windows에서는 가상환경 활성화 명령으로 `venv\Scripts\activate`를 사용합니다. Tkinter 사용 가능 여부는 `python -m tkinter`로 확인할 수 있습니다. 모듈이 없다면 사용하는 Python 배포판 또는 운영체제에 맞는 Tkinter 패키지를 설치해야 합니다.

macOS에서는 위와 같이 `venv`를 만든 뒤 `run_automation.command`로도 실행할 수 있습니다. 이 파일은 프로젝트 디렉터리로 이동하고 `venv`를 활성화한 뒤 `main.py`를 실행합니다. 의존성 버전을 고정한 파일은 현재 없습니다.

## 빠르게 사용하기

1. 앱에서 **CSV 파일 선택**을 눌러 `sample_data/sample_gangwon.csv`를 선택합니다.
2. **시/도 선택**에서 `강원특별자치도`를 선택합니다.
3. **실행 (정리 + 비교)**를 눌러 포함된 법정동 코드 목록과 비교합니다.
4. 좌표를 정렬하려면 **중앙 정렬 CSV 저장**을 누릅니다.
5. 정렬된 좌표로 Swift 코드를 만들려면 **CSV 파일 선택**으로 생성된 `sample_gangwon_centered.csv`를 다시 선택한 뒤 **Swift 코드로 저장**을 누릅니다.

각 버튼은 현재 선택한 CSV를 독립적으로 처리합니다. 결과 파일이 자동으로 다음 작업의 입력이 되지 않으므로, 변환을 이어서 수행할 때는 결과 CSV를 다시 선택해야 합니다. 같은 출력 경로가 이미 있으면 덮어씁니다.

## 입력 데이터

### 일반 CSV

포함된 샘플은 다음 형식입니다.

```csv
y,x,zone_code,pnus
4,12,5182000000,[5182031000]
5,12,5182000000,[5182034000]
```

| 컬럼 | 의미 및 사용처 |
| --- | --- |
| `x`, `y` | 격자 좌표. 중앙 정렬 및 Swift 변환에 사용 |
| `zone_code` | 격자의 지역 코드. 코드 자르기 및 Swift 변환에 사용 |
| `pnus` | 리스트를 문자열로 저장한 값. 누락 비교 및 끝자리 자르기에 사용 |

`pnus`에 값이 여러 개면 CSV 필드를 따옴표로 감쌉니다. 예: `"[5182031000, 5182034000]"`.

샘플의 `pnus`는 **10자리 법정동 코드**입니다. 반면 아래 PNU 정리 기능은 **19자리 PNU**를 출력합니다. 비교 기능은 자릿수 변환 없이 숫자 자체를 비교하므로, 법정동 코드 누락을 확인할 때는 `pnus`가 기준 목록과 같은 10자리 코드인지 확인해야 합니다.

### PNU 정리용 CSV

**PNU 정리 및 저장**은 일반 CSV와 다른 컬럼을 요구합니다.

```csv
row_index,col_index,BGD,PNU_list
4,12,5182031000,"5182031000100010000,5182031000100020000"
```

- `row_index`, `col_index`: 격자의 행과 열
- `BGD`: PNU 앞 10자리와 비교할 법정동 코드
- `PNU_list`: 대괄호 없이 쉼표로 구분한 PNU 문자열

처리 결과는 `y,x,zone_code,pnus` 컬럼으로 저장됩니다. `BGD` 또는 `PNU_list`가 결측인 행은 제거하며, 숫자 PNU는 최소 19자리로 왼쪽을 `0`으로 채웁니다. 중복 PNU는 터미널에 경고하고 그대로 유지합니다. BGD와 앞 10자리가 다르거나 숫자가 아닌 항목도 결과에 유지하면서 별도 TXT에 기록합니다. 파일명에 `_merged`가 붙지만, 행 병합이나 중복 제거는 하지 않습니다.

### 법정동 기준 목록

`legal_zone_code_data.txt`는 `법정동코드`, `법정동명`, `폐지여부` 컬럼을 가진 UTF-8 탭 구분 파일입니다. 비교 시 선택한 시/도로 이름이 시작하고, `폐지여부`가 `존재`이며, 이름이 `리`로 끝나지 않는 행을 사용합니다. 기준 목록은 저장소에 포함된 파일을 사용하며 자동 갱신하지 않습니다.

## 기능과 출력 파일

아래에서 `<입력명>`은 확장자를 제외한 입력 파일명입니다. 별도 표시가 없으면 입력 CSV와 같은 폴더에 저장합니다.

| GUI 버튼 | 필요한 입력 | 처리 및 출력 |
| --- | --- | --- |
| PNU 정리 및 저장 | `row_index,col_index,BGD,PNU_list` | `<입력명>_merged.csv`, `<입력명>_unmatched_pnus.txt` |
| 실행 (정리 + 비교) | `pnus`, 시/도 | 공백·중복 등을 정리한 뒤 양방향 코드 비교. 아래 3개 파일을 **현재 작업 디렉터리**에 저장 |
| 중앙 정렬 CSV 저장 | `x,y` | 좌표 범위의 중심을 22×22 격자에 맞춰 이동하여 `<입력명>_centered.csv` 저장 |
| Swift 코드로 저장 | `x,y,zone_code`, 시/도 | 시/도 코드를 키로 하는 `zoneMap`을 `<입력명>.swift`로 저장 |
| zone_code 자르기 및 저장 | `zone_code`, 남길 자릿수 | 앞 N자리만 남기고 정수로 변환하여 `<입력명>_trimmed_N.csv` 저장 |
| pnus 자르기 및 저장 | `pnus`, 시/도 | `00`으로 끝나는 값의 마지막 두 자리만 제거하여 `<시도코드>.csv` 저장. 예: 강원 `51.csv` |

비교 기능의 출력은 다음과 같습니다. 정리된 CSV 자체는 별도로 저장하지 않습니다.

- `filtered_<시도명>.txt`: 조건에 맞게 필터링한 법정동 기준 목록
- `누락_from_csv.csv`: 기준 목록에는 있지만 입력 CSV의 `pnus`에는 없는 코드
- `누락_from_txt.csv`: 입력 CSV의 `pnus`에는 있지만 필터링된 기준 목록에는 없는 코드

중앙 정렬은 좌표를 확대·축소하지 않고 이동만 합니다. 좌표 범위의 너비나 높이가 22를 초과하여 이동 결과가 음수가 되면 오류를 표시합니다.

`pnus` 자르기는 자릿수 입력란을 사용하지 않습니다. 끝이 `00`이 아닌 값은 유지하고 알림에 집계하며, 리스트 해석에 실패한 행은 빈 리스트로 저장합니다. 이 기능은 19자리 PNU를 10자리 법정동 코드로 변환하는 기능이 아닙니다.

Swift 출력 형식은 다음과 같습니다. 사용하는 Swift 프로젝트에 `Zone` 타입이 별도로 정의되어 있어야 합니다. 좌표나 코드의 정수 변환에 실패한 행은 출력에서 제외됩니다.

```swift
let zoneMap: [Int: [Zone]] = [
    51: [
        Zone(x: 12, y: 4, zoneCode: 5182000000),
    ],
]
```

## QGIS에서 격자 재배치

`qgis/space_rearrange.py`는 QGIS Python 콘솔의 편집기에서 실행하는 별도 스크립트입니다.

1. QGIS 프로젝트에 `joined_layer`라는 이름의 레이어를 준비합니다. 다른 이름을 쓰려면 스크립트의 `layer_name`을 수정합니다.
2. 레이어에 `row_index`, `col_index`, `BGD`, `PNU` 필드가 있어야 합니다. 행·열 인덱스는 0~21의 정수인 22×22 격자를 전제로 합니다.
3. QGIS Python 콘솔 편집기에서 스크립트를 열어 실행합니다.
4. 콘솔의 PNU 개수, 누락, BGD 배정 실패, 혼합 BGD 검사 결과를 확인합니다.
5. 생성된 `PNU_distributed_final` 메모리 레이어를 CSV로 내보내면 GUI의 **PNU 정리 및 저장**에 사용할 수 있습니다.

스크립트는 각 셀에서 가장 많은 BGD를 우선 배정하고, 나머지를 같은 BGD의 이웃 셀이나 가까운 셀로 이동합니다. 필요하면 기존 셀을 밀어 빈 공간을 확보하며, 배정할 수 없는 항목은 콘솔에 보고합니다. 결과는 메모리 레이어이므로 보관하려면 파일로 내보내야 합니다. 점 좌표 `(열, -행)`은 격자 표시용이며 실제 지리 좌표가 아닙니다.

## 코드 구성

| 파일 | 역할 |
| --- | --- |
| `main.py` | Tkinter GUI, 파일 선택 및 기능 연결 |
| `data_to_csv.py` | PNU 검사 및 일반 CSV 형식으로 변환 |
| `cleaner.py` | 컬럼명·문자열 공백 정리, 결측 행·중복 행 제거 처리 |
| `extractor.py` | 시/도별 법정동 기준 목록 필터링 |
| `comparer.py` | `pnus`와 기준 법정동 코드의 양방향 차집합 계산 |
| `csv_to_center.py` | 22×22 격자 중앙 정렬 |
| `csv_to_swift.py` | Swift `zoneMap` 코드 생성 |
| `zone_code_trimmer.py` | `zone_code` 앞 N자리 추출 |
| `pnus_trimmer.py` | `pnus` 값의 끝 두 자리 `00` 제거 |
| `qgis/space_rearrange.py` | QGIS 레이어의 BGD별 PNU 재배치 및 검사 |
| `legal_zone_code_data.txt` | 비교용 법정동 코드 목록 |
| `sample_data/sample_gangwon.csv` | 일반 CSV 형식의 강원 샘플 |
| `run_automation.command` | macOS용 가상환경 활성화 및 앱 실행 |

## 현재 구현의 주의사항

- 비교 모듈은 `pnus` 문자열을 `eval()`로 해석합니다. **신뢰할 수 있는 CSV만 비교 기능에 입력해야 합니다.** 해석에 실패한 값은 비교에서 제외됩니다.
- 코드 자르기는 정수 변환을 포함하므로 선행 `0`을 보존하지 않습니다. `zone_code` 자릿수에는 양의 정수를 입력합니다.
- GUI의 시/도 선택은 비교 기준과 출력 코드·파일명에 사용됩니다. 입력 CSV의 행을 해당 시/도로 자동 필터링하지 않습니다.
- 자동화 테스트는 현재 포함되어 있지 않습니다. 변환 결과는 출력 파일과 터미널의 검사 메시지로 확인합니다.
